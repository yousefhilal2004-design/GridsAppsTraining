# Day 01 - HTML Foundations & Semantic Structure

## About the project
This is my Day 01 project for the Full Stack Web Development internship. I made a simple company homepage and a personal profile page using HTML.

## What I learned
- How an HTML page is structured.
- How to use headings, paragraphs, lists, links, and images.
- What metadata is used for.
- How semantic tags like `header`, `nav`, `main`, `section`, `article`, and `footer` help organize a page.

## Project files
- `index.html` - the company homepage.
- `profile.html` - my H01 profile challenge.
- `images/profile-placeholder.svg` - a simple image for my profile page.

## How to run
Open `index.html` in a web browser. Use the navigation links to visit different sections and the profile page.

## Section vs Article
I use `section` to group content about one topic, such as services. I use `article` for content that can stand on its own, such as a news post.
