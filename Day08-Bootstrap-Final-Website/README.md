# Day 08 — Bootstrap Final Website

## What I built
I made a 10-page website for a fictional software company called Grids Tech. I used Bootstrap 5.3, my own CSS file, and a small JavaScript file.

## Pages
Home, About, Services, Portfolio, Team, Pricing, Blog, FAQ, Contact, Register.

## Things I practiced
- Bootstrap containers, rows, columns, cards and buttons.
- Responsive navigation with an **offcanvas menu** on small screens.
- **Accordion** questions on the FAQ page.
- **Modal** contact form and a **carousel** on the homepage.
- Contact and registration forms with browser validation.
- Keyboard focus, a skip link, and responsive layouts.

## Important notes
- This is a student practice project, not a real company website.
- Prices and services are examples only.
- The forms do not send or save real data. There is no backend.
