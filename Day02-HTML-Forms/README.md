# Day 02 — HTML Forms & Multi-Page Architecture

## What I built

Today I made a small website with six connected pages: Home, About, Services, Blog, Contact, and Registration. I used simple HTML because we will learn CSS in another training day.

## What I learned

- How to connect pages using relative links like `about.html`.
- How to create forms using `form`, `label`, `input`, `select`, and `textarea`.
- How to use basic HTML validation like `required`, `type="email"`, and `minlength`.
- How to add a simple table and an image.
- How to group content with semantic HTML tags.

## How to run

Open `index.html` in a browser. Use the navigation links to visit the other pages.
