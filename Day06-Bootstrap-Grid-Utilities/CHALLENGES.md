# Day 06 — Challenge Notes

## B01 — Pricing
**Goal:** Build three pricing cards with Bootstrap.

I used `container`, `row`, `col-12`, `col-md-6`, `col-lg-4`, `g-4`, `p-4`, and `btn` classes. The cards stack on small screens.

## B03 — Dashboard Summary
**Goal:** Make a responsive dashboard overview.

I used `row`, `col-sm-6`, `col-xl-3`, `d-flex`, `justify-content-between`, `badge`, `progress`, and `table-responsive` classes.

## Extra practice
Try changing one `col-lg-4` class to `col-lg-6`, refresh the page, and see how the layout changes. Change it back afterward.
