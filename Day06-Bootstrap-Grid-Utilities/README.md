# Day 06 — Bootstrap Setup, Grid & Utilities

## What I built
I made a small Bootstrap website with three connected pages:
- `index.html`: a homepage with a hero section and responsive cards.
- `pricing.html`: Challenge B01, a pricing layout with three sample plans.
- `dashboard.html`: Challenge B03, a dashboard with summary cards, progress bars and a table.

I used **Bootstrap 5.3.8** with a CDN, plus my own CSS file (`css/styles.css`) to change the colors and details.

## What I learned
- `container` keeps content centered.
- `row` groups columns.
- `col-12 col-md-6 col-lg-4` changes a layout from one column to two to three.
- `g-4`, `p-4`, `py-5`, `d-flex`, `gap-3` and `text-center` help with spacing and layout.
- Bootstrap gives me useful classes so I do not have to write CSS for everything.
