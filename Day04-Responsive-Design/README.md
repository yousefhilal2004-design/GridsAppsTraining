# Day 04 — Flexbox, Grid & Responsive Design

## What I built
I updated my Grids Tech website from Day 03. It now changes layout to work better on phones, tablets and desktop screens.

## What I learned
- Flexbox is good for a navigation bar because links can wrap when there is less space.
- CSS Grid is good for cards because I can change the number of columns.
- Media queries apply different styles to different screen widths.
- A responsive image uses `max-width: 100%` so it fits inside its container.
