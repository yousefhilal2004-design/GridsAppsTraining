# Day 04 — Screenshots to submit

1. Open `index.html` in Chrome or Edge.
2. Press **F12**, then click **Toggle device toolbar** (or press Ctrl+Shift+M).
3. Set the size to **375 x 812** (mobile) and save a screenshot as `screenshots/mobile.png`.
4. Set the size to **768 x 1024** (tablet) and save `screenshots/tablet.png`.
5. Set the size to **1440 x 900** (desktop) and save `screenshots/desktop.png`.
6. Check that you can see all content without horizontal page scrolling.
7. If you find an issue, fix the HTML/CSS, test again and explain the fix in your README.

Screenshots are not pre-filled because they must show your own browser testing.
