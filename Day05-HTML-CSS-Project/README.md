# Day 05 — HTML/CSS Project Delivery

## What I built
I finished a responsive Grids Tech practice website using HTML and CSS. The website now has **12 connected pages**. Grids Tech is a made-up company for my internship project.

## Pages
1. `index.html` — Home
2. `about.html` — About
3. `services.html` — Services
4. `portfolio.html` — Portfolio
5. `team.html` — Team
6. `pricing.html` — Example packages
7. `blog.html` — Blog
8. `faq.html` — FAQ
9. `process.html` — Process
10. `resources.html` — Resources
11. `contact.html` — Practice contact form
12. `registration.html` — Practice registration form

## What I practiced
- Semantic HTML and links between pages.
- One external CSS file shared across all pages.
- Flexbox navigation and CSS Grid cards.
- Media queries for phone, tablet and desktop widths.
- CSS variables for colors and spacing.
- Labels and browser validation in forms.
- Keyboard focus and a skip-to-main link.

## How to run
Open `index.html` in Chrome, Edge or Firefox. You do not need to install anything. Use the navigation links to move between pages.

## Important note about forms
The contact and registration forms are just HTML practice. They check required fields in the browser, but they **do not send or save information to a server**. Do not enter real personal details.
