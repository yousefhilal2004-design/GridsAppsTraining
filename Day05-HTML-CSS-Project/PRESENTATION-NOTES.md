# Day 05 — Live Demo Notes

1. **Homepage:** I created this website to practice HTML and CSS during my training.

2. **Website Pages:** My website has 12 pages, including Home, Services, Portfolio, FAQ, and Contact.

3. **Navigation and CSS:** I used the same navigation menu and CSS file on all pages to keep the website organized and consistent.

4. **Semantic HTML:** I used tags like `header`, `nav`, `main`, `section`, and `footer` to organize my pages.

5. **CSS Grid:** I used CSS Grid to organize the cards and media queries to change the layout on different screen sizes.

6. **Accessibility:** I added keyboard focus styles and a skip link to make navigation easier.

7. **Contact Form:** I used HTML validation to check the email and required fields. The form does not send data because there is no backend.

8. **GitHub:** I organized my project files, screenshots, and README and saved my progress using Git commits.

9. **Bug Fixing:** I practiced fixing layout and spacing problems while testing the website.
